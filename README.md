# 우르르! 몬스터 대작전

친구들을 모아 몬스터를 물리치는 모바일 세로형 2.5D 게임의 1스테이지 MVP입니다.
HTML5 Canvas, CSS, JavaScript만 사용하며 서버, API, 외부 CDN이 필요 없습니다.

## 실행

**바로 플레이:** https://llutar-design.github.io/urr-monster-operation/ (휴대폰에서도 이 주소를 열면 됩니다)

내려받은 폴더에서는 `index.html`을 더블클릭해 브라우저로 엽니다.

휴대폰에서 실행하려면 이 폴더를 웹으로 제공해야 합니다. PC와 휴대폰이 같은 Wi-Fi에 있을 때 이 폴더에서 아래 명령을 실행합니다.

```
python -m http.server 8000
```

그다음 휴대폰 브라우저에서 `http://PC의-IP주소:8000`을 엽니다.

## 조작

| 환경 | 조작 |
| --- | --- |
| 모바일 | 화면을 손가락으로 좌우 드래그 |
| PC | 마우스 드래그, 또는 ←, → 키 (A, D 키도 가능) |

사격은 자동입니다. 좌우 게이트 중 하나를 골라 지나가고, 몬스터와 장난감 블록을 피하며 마지막 거대 몬스터를 물리치면 성공입니다.

`index.html?stage=redgate`로 열면 빨간 -5 게이트를 확인할 수 있습니다. 사양의 1스테이지 구성에는 -5 게이트가 없습니다.

## 테스트

Node.js 22 이상이 필요하며 설치할 패키지는 없습니다.

```
node tests/logic.test.js
node tests/browser.test.js [스크린샷 저장 폴더]
```

- `logic.test.js`: 게임 로직 전체와 게이트 선택별 끝까지 플레이 시뮬레이션
- `browser.test.js`: 설치된 Chrome 또는 Edge를 화면 없이 띄워 실제 터치, 마우스, 키 입력으로 한 판을 끝까지 진행 (약 2분)

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/config.js` | 수치와 스테이지 데이터 (밸런스 조정 위치) |
| `js/state.js` | 한 판의 상태 생성. 재시작은 새 상태를 만드는 것 |
| `js/squad.js` | 대형, 이동, 인원 증감 |
| `js/gates.js` | 숫자 게이트, 장애물 |
| `js/combat.js` | 자동 사격, 총알 충돌, 몬스터, 보스 |
| `js/game.js` | 고정 스텝 1회 진행, 승패 판정 |
| `js/input.js` | 터치, 마우스, 키보드 입력 |
| `js/render/*` | 투영, 스프라이트, 배경, 캐릭터, 효과, HUD. 게임 상태는 읽기만 함 |
| `js/ui.js` | 시작, 게임 방법, 결과 화면과 버튼 |
| `js/main.js` | 앱 흐름과 고정 시간 스텝 루프 |
